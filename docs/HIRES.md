# 2배 해상도 UI — 그림은 한국 초기판 것으로

지금 빌드(중국판 7.7)의 주행 HUD 는 `Atlas_InGame` 한 장(512×512)에 조각
81개가 들어 있습니다. 2013년 폰 기준이라 요즘 1080p 화면에서는 눈에 띄게
뭉갭니다.

한국 초기판(`8.apk`)에는 **같은 이름의 조각이 정확히 두 배 크기로**
들어 있습니다. 그때는 2048×2048 판을 썼습니다.

```
CheckPoint   우리 347x18    초기판 694x36
GaugeBar     우리 209x134   초기판 418x268
HUDEco0      우리  20x12    초기판  40x23
```

이름이 겹치는 조각 111개 중 **96개가 배율 1.96~2.00** 이었습니다(나머지도
아틀라스 포장 여백 때문에 1픽셀씩 어긋난 것뿐입니다).

```
python tools/hires.py --scan     무엇을 몇 개나 키울 수 있나
python tools/hires.py --png OUT  새 판을 PNG 로만 뽑아 본다
python tools/hires.py            바꾼다
python tools/hires.py --restore  backup/hires 에서 되돌린다
```

## 무엇을 키웠나

| 아틀라스 | 조각 | 초기판에 있음 | 판 크기 |
|---|---|---|---|
| **Atlas_InGame** (주행 HUD) | 81 | 66 | 512² → 1024² |
| **Atlas_Cutin** (컷인) | 7 | 7 | 512² → 1024² |
| **Atlas_CarIcon** (차 아이콘) | 83 | 30 | 1024×512 → 2048×1024 |

초기판에 없는 것들(중국판이 나중에 더한 것)은 우리 것을 2배로 늘려
채웁니다 — 더 선명해지진 않지만 나빠지지도 않고, 판 전체가 한 축척으로
유지됩니다.

`Atlas_CarIcon` 은 83개 중 30개만 초기판에 있습니다. **초기판에 R 등급이
아예 없어서**, 같은 차라도 A·B·S 는 또렷하고 R 은 아닌 식으로 선명도가
섞입니다. 그래도 R 쪽이 지금보다 나빠지진 않습니다.

**안 키운 것과 그 까닭**

| 아틀라스 | 까닭 |
|---|---|
| `Atlas_GameTutorial` | 8/9 가 있지만 도움말 팝업은 `notutorial` 이 꺼 뒀다 |
| `Atlas_LobbySkillIcon` | 초기판에 같은 이름이 **하나도** 없다 |
| `Atlas_SpecialCarIcon` · `Atlas_EventPop` | 마찬가지로 0개 |

## 자리를 다시 짜지 않는다

512 판의 조각 자리를 **그냥 두 배** 한 자리에 놓습니다. 겹치지 않던 것이
두 배가 되어도 겹치지 않으므로 새로 포장할 까닭이 없고, 조각 사이 여백도
같은 비율로 늘어나 번짐이 더 나빠지지 않습니다. 포장 알고리즘도, 좌표
표도 새로 짤 일이 없습니다.

## NGUI 쪽 셈 — 왜 화면에서 커지지 않나

- 이 아틀라스를 쓰는 위젯이 **113개인데 전부 `Simple`** 입니다(전수 확인).
  Simple 은 위젯의 트랜스폼 스케일에 UV 를 그대로 입히므로, 조각이 커져도
  화면에서 커지지 않습니다. **더 촘촘해질 뿐입니다.**
- 그래도 `UIAtlas.mPixelSize` 를 **1.0 → 0.5** 로 둡니다.
  `MakePixelPerfect` · `SlicedFill` · `TiledFill` · `get_border` 넷이 이
  값을 곱하므로, 나중에 누가 그 길로 들어와도 크기가 그대로입니다.
- 이 아틀라스를 쓰는 `UIFont` 는 없습니다. `TxtFont0..9` · `TxtSpeed0..9`
  같은 숫자도 글꼴이 아니라 낱장 `UISprite` 입니다(확인).

## 가장자리

조각을 옮겨 담을 때 **알파를 곱해 두고 넓이 평균(BOX)으로** 크기를
맞춥니다. 그냥 늘리거나 줄이면 실루엣 바깥의 (0,0,0,0)이 색 계산에
끼어들어 둘레에 검거나 알록달록한 테가 생깁니다. 트로이 아이콘을 만들 때
같은 데를 두 번 밟았습니다(`docs/TROY.md` 6절).

## `.splitN` 함정 — 그리고 통짜와 조각이 어긋나 있던 것

**엔진은 `sharedassets1.assets` 통짜가 아니라 `.split0` `.split1` 조각을
읽습니다.** 통짜만 고치면 아무 일도 안 일어납니다. 이 프로젝트는 예전에
이미 한 번 걸렸고(`research/splitassets.py` 의 머리말에 그 기록이 있습니다),
이번에도 같은 함정이 그대로 놓여 있었습니다.

그래서 `hires.py` 는 고친 뒤 조각을 **다시 만듭니다**(1MiB 씩). 조각 수가
늘면(2개 → 3개) 남는 옛 조각은 지웁니다. 통짜도 같이 남겨 두 쪽이
어긋나지 않게 합니다.

### 손대기 전에 이미 어긋나 있었다

작업 트리를 재 보니 통짜와 조각이 **원래 달랐습니다.**

| 파일 | 통짜 | 조각 합 | 다른 바이트 |
|---|---|---|---|
| `sharedassets1.assets` | 1,559,064 | 1,559,064 | 3개 |
| `sharedassets2.assets` | 2,092,408 | 2,092,344 | 1,774,950개 |

`sharedassets1` 의 3바이트를 따라가 보니 이랬습니다.

- 외부 파일 목록의 `type` 필드 하나 (`0x0e` → `0`) — 우리 쓰기 도구가
  0 으로 쓰는 자리라 의미는 없습니다.
- **`mMaxLineWidth = 553`** — `tools/fitlabels.py` 가 넘치는 한글 라벨에
  넣어 준 줄바꿈 폭입니다. **조각에는 0 그대로**입니다.

즉 `fitlabels` 가 고친 그 라벨은 **엔진에 닿은 적이 없습니다.** 이번에
조각을 다시 만들면서 함께 살아났습니다.

`sharedassets2` 는 통짜가 `data_offset` 까지 다른 **다른 배치**입니다. 하지만
뜯어 보니 **내용 차이는 라벨 두 개뿐**이었습니다. 오브젝트 207개 · 외부
참조 · pathID 가 전부 같고, 다른 것은 이것뿐입니다.

| pathID | 통짜 | 조각(2013 원본) |
|---|---|---|
| 139 | `10일 전` | `10天前` |
| 145 | `타이어를 보내왔습니다` | `给你赠送了轮胎` |

**그리고 이 둘은 화면에 안 나옵니다.** 프리팹에 적어 둔 자리표시자일 뿐,
게임이 실행 중에 문자열표로 덮어씁니다. 수신함을 실기로 열어 확인했습니다 —
`FriendPresent = {0}님이 {1}를 {2}개 보내셨습니다.` 와
`KeepTireTime` 이 그대로 그려지고, 저 두 문구는 어디에도 안 보입니다.

그래서 **`sharedassets2` 는 고칠 것이 없습니다.** 어긋나 있지만 무해합니다.

> 한때 이 차이를 "태극호 아이콘 작업의 흔적"으로 적었는데 **틀렸습니다.**
> `Taegeuk_A/B/R/S` 아이콘은 2013년 조각 원본에 이미 들어 있는 **게임 자체의
> 그림**입니다(`x77` 과 `x77o` 의 조각이 md5까지 같습니다). 이 프로젝트가
> 만들었다 뺀 자작 차 태극호와는 이름만 같을 뿐 관계가 없습니다.

덤으로 알게 된 것: **`x77o` 는 원본 사본이 아닙니다.** 그 안의
`sharedassets1/2` 통짜도 이미 이 프로젝트의 편집이 들어가 있어 `x77` 것과
바이트까지 같습니다. **`.splitN` 조각만이 마지막 원본입니다.**

## 실기 확인

주행 화면에서 거리 · 속도 · 점수 · 연료계 · 방향 화살표 · JUMP 단추가
**전부 같은 자리 같은 크기**로 나오고, 숫자 가장자리가 눈에 띄게
깨끗해졌습니다. 1117m / 189km/h 까지 달려 이상 없었습니다.

차 아이콘도 순위표에서 눈에 띄게 또렷해졌습니다(머스탱 아이콘의 줄무늬 ·
창틀 · 바퀴가 살아났습니다).

`Atlas_Cutin`(아이템을 먹거나 부스터를 쓸 때 튀어나오는 캐릭터 컷인)은
**눈으로 잡지 못했습니다.** 잠깐 스치는 연출이라 adb 로 맹목 조작하며
찍어서는 안 걸렸습니다. 다만 구조는 확인했습니다 — 이 아틀라스를 쓰는
위젯은 `level0` 안에 **여덟 개뿐이고 전부 `Simple`** 입니다. 실기로 확인한
`Atlas_InGame`(113개 전부 Simple)과 같은 셈이므로 같이 맞을 것으로 봅니다.
확정하려면 주행 중 아이템을 먹는 순간을 봐야 합니다.

## 되돌리기

```
python tools/hires.py --restore
```

`backup/hires` 에 통짜와 조각 원본이 그대로 있습니다. 되돌릴 때 지금
조각을 먼저 지우므로 조각 수가 줄어도 쓰레기가 남지 않습니다.
