# 드라이버 보이스 — 한국어가 들리지 않던 까닭

한국 초기판(`8.apk`, 2013-01)에는 기본 드라이버 넷의 한국어 보이스가
넉 벌 80개 온전히 들어 있습니다. `voicefix.py --kr` 로 그것을 작업 트리에
제대로 옮겨 넣었고, 바이트까지 일치하는 것도 확인했습니다.

**그런데 게임에서는 영어가 들립니다.**

```
x77 트리 == 초기판 한국어 : 80/80    ← 제대로 썼는데
x77 트리 == 번들          :  0/80    ← 게임은 번들 것을 쓴다
```

---

## 한 줄로 말하면, 넣은 자리가 틀렸습니다

`Generic_Title.__ChaResLoad` 의 IL 을 읽으면 이렇습니다.

```
if (name.StartsWith("Character VOX/")) {
    v = __ChaFromBundle(name);      // ← 이 경로만 번들을 먼저 본다
    if (v) return v;
}
return Resources.Load(name) ?? __ChaFromBundle(name);
```

보이스만 **번들 우선**입니다. 다른 자산은 전부 `Resources.Load` 가 먼저고요.

이렇게 된 데는 까닭이 있습니다. `tunnelfix.cs` 의 주석이 그 의도를 적어
두었습니다 — 중국판 Resources 에도 기본 드라이버 넷의 보이스가 있는데
**중국어 더빙**이라, 한국어 클립을 번들에 같은 이름으로 넣고 이 경로만
번들이 이기게 만든 것입니다.

의도는 맞았는데 **한국어 클립이 번들이 아니라 트리로 갔습니다.** 번들에는
카카오판에서 복원해 온 11명분이 들어 있었고, 그 안에 기본 넷도
있었습니다. 그래서 번들이 이기고, 트리의 한국어는 한 번도 안 쓰였습니다.

## 고침

`voicefix.py` 가 트리를 쓴 뒤 **번들도 갈아 끼웁니다.**

```
python tools/voicefix.py --kr
   트리 80개를 바꿨습니다. 원본은 backup/ 에 있습니다.
   번들 쪽도 갈아 끼웁니다 — 이쪽이 실제로 들리는 자리입니다.
     pack.dat 오브젝트 2839개 중 80개 교체 · 7542556 → 7722260바이트
```

번들 알맹이(`pack.dat`)의 오브젝트를 갈아 끼우고 다시 씌웁니다
(`packadd.replace`). `backup/bundle` 의 바탕본도 같이 고칩니다 — 그래야
`addtroy` 가 바탕본을 되살려도 보이스가 안 사라집니다.

결과: 번들 안 VOX 220개 중 **초기판 녹음 80 · 카카오판 녹음 140**.

### 덧붙임 — 둘 다 한국어입니다

뽑아서 들어 본 결과(2026-08-24), **열한 명 전부 한국어**였습니다.
카카오판에서 복원해 온 일곱 명도 한국어 더빙입니다.

이 저장소는 한동안 카카오판을 '동남아/영문판'으로 적어 두었는데
**틀린 기록이었습니다.** 그 판의 차 이름이 `Garuda`·`Hummie`·`Magnum`
이라 그렇게 넘겨짚은 것이고, 소리를 들어 본 적은 없었습니다.
그러니 "기본 넷만 한국어고 나머지는 영어라 말이 섞인다"던 말도 취소합니다.

그래도 번들 쪽을 고친 것은 그대로 뜻이 있습니다. 고치기 전에는 트리에
써 넣은 한국어가 **아예 안 쓰이고** 있었으니까요.

## 들어 보시려면

```
python tools/voxout.py          export/voice 에 220개를 뽑는다
python tools/voxout.py --one    드라이버마다 대표 한 마디만
```

**번들에서 뽑습니다.** 트리가 아닙니다 — 실제로 들리는 쪽이 번들이니까요.
폴더 이름에 `초기판` / `카카오판` 이 붙습니다(둘 다 한국어이므로 말이
아니라 **출처**를 적습니다).

### 확장자는 매직으로 정합니다

게임 데이터에는 `m_Type=13`(FMOD 로는 OGGVORBIS)이라고 적혀 있지만,
**실제 내용은 MP3** 입니다(`\xff\xf3`, MPEG2 Layer III 16kHz mono).
네 개는 `m_Type=20` 에 **WAV**(`RIFF`)가 들어 있습니다. 적힌 값을 믿고
`.ogg` 를 붙이면 안 열리는 파일이 나옵니다. 첫 바이트로 정해야 합니다.

## 넷은 드라이버가 아니라 **차**다

`Player::_GetCutinModel()` 의 IL 이 그대로 말해 준다.

```
carName == "Poli"  → 6 POLY      carName == "Amber" → 7 AMBER
carName == "Roy"   → 8 ROI       carName == "helly" → 9 HELLY
그 밖에는 driverType(Driver_1~8) → 0,1,2,3,4,5,10,11
```

**차 이름이 드라이버를 덮어쓴다.** 그 넷을 타면 드라이버가 누구든 무시되고
차 자신의 얼굴(컷인)과 목소리가 나온다. 로보카 폴리 네 대다.

그래서 보이스 폴더의 짝은 이렇게 확정된다.

| 폴더 | `eCutinModelType` | 게임 안 |
|---|---|---|
| `DOKANG` | 0 | Char1 도 강현 |
| `SARA` | 1 | Char2 Sarah Cha |
| `BIN` | 2 | Char3 빈 경유 |
| `NAYOUBI` | 3 | Char4 나 연비 |
| `PIG` | 4 | Char5 김준현 |
| `GYARU` | 5 | Char6 갸루상 |
| `POLY` | 6 | **차** Poli |
| `AMBER` | 7 | **차** Amber |
| `ROI` | 8 | **차** Roy |
| `HELLY` | 9 | **차** helly |
| `ANGRY` | 10 | Char7 앵그리성호 |
| (없음) | 11 ROPE | Char8 정신이 — **보이스가 없다** |

`Char8 정신이`의 보이스는 우리가 가진 어느 판에도 없다.

## 폴리 · 앰버 · 로이는 **모델이 없다**

넷 중 차 모델이 남아 있는 것은 **helly 뿐**이다. 가진 배포판을 전수로
훑었다 — 오브젝트 이름으로도, `mainData` 의 자원 색인으로도 없다.

| 배포판 | helly | Poli · Amber · Roy |
|---|---|---|
| 고고고 레이서 1.4.2 | 차 45항목 | 없음 |
| 한국 7.7.0 | 차 45항목 | 없음 |
| 중국판 7.7 | 없음(우리가 번들로 넣었다) | 없음 |
| 한국 초기판 8.apk | 없음 | 없음 |

남아 있는 것은 **껍데기뿐**이다.

- 자동차 샵 아이콘 — `Atlas_SpecialCarIcon` 에 `Poli_A/R/S` · `Amber_A/R/S`
  · `Roy_A/R/S` 가 그대로 있다
- 보이스 스무 마디씩 (카카오판에서 복원한 번들 안에)
- 위 `_GetCutinModel` 의 코드 갈래

즉 **차를 부를 준비는 다 되어 있는데 차만 없다.** 이 게임은 차를 CDN
(`AssetBundleManager`)에서 받아 왔고 그 CDN 은 2014년에 죽었다. helly 만
살아남은 것은 그 차가 APK 안에 통째로 들어 있는 판(고고고 레이서 ·
한국 7.7.0)이 우리 손에 있었기 때문이다.

되살리려면 **모델을 새로 만드는 수밖에 없다.** 아이콘이 남아 있으니 생김새는
알 수 있고, 트로이를 넣은 길(`docs/TROY.md`)을 그대로 쓰면 된다.
