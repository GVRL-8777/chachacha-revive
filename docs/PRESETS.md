# 판 가르기 — 이제 **세이브 파일**입니다

APK 는 **한 벌**입니다.

```
앱 이름   다함께 차차차
패키지    com.cjenm.chachacha.revive
폴더      /storage/emulated/0/Android/data/com.cjenm.chachacha.revive/files
```

예전에는 프리셋마다 앱을 갈랐습니다(`.rag` · `.rich`). 갈라 놓으니 같은
게임이 홈 화면에 둘로 보이고, 세이브도 따로 놀고, 어느 쪽이 어느 쪽인지
열어 봐야 알았습니다. 이제 **시작 상태는 세이브가 정합니다.**

## 세이브 프리셋

`chastate.PRESETS` 의 두 벌이 밑그림입니다. 런처의 **저장 및 내보내기** 탭에서 `＋ 새로 만들기` 를 누르면 밑그림을 골라 세이브를 하나 만듭니다.

이름에서 판 이름(rag · rich 따위)은 걷어냈습니다. 어느 쪽이 어느 쪽인지
번호와 설명으로만 부릅니다.

| | 프리셋 01 · 처음부터 | 프리셋 02 · 전부 해금 |
|---|---|---|
| 열쇠 | `bespontovnyj-pirozhok` | `malchiki-mazhory` |
| 골드 | 50,000 | 999,999,999 |
| 트로피 | 10 | 999,999,999 |
| 타이어 | 900 | 998 |
| 자동차 | 아베오 한 대 | 30대 전부 |
| 캐릭터 | 도 강현 한 명 | 12명 전부 |
| 아이템 | 전부 0 | 7종 99개씩 |

골드·트로피 상한은 9자리입니다. 화면에서 잘리지 않는 것을 실기로
확인했습니다. **강화공구상자만 0/1** 입니다 — 클라이언트가
`Mathf.Clamp(값, 0, 1)` 로 자릅니다.

## 쓰는 순서

1. **세이브** — 프리셋으로 만들거나, 있는 것을 고릅니다. 다른 탭에서
   고치고 저장하면 그 세이브가 바뀝니다.
2. **기기 연결** — 고른 세이브를 폰에 넣습니다. 앱이 한 벌이라
   **세이브만 갈아 끼우면 다른 판이 됩니다.**
3. **APK 굽기** — 지금 고른 세이브를 구워 넣은 APK 를 만듭니다.

세이브는 `파일로 내보내기` · `파일에서 불러오기` 로 주고받습니다.

## 도장을 없앴습니다

예전 로컬 APK 는 세이브의 `preset` 도장이 제 것과 다르면 **버리고 새로
시작**했습니다. 앱이 갈라져 있을 때를 위한 장치였는데, 이제는 남의
세이브란 게 없으므로 걷어냈습니다. 어떤 세이브든 받아들이고, 도장이
다르면 기록만 남깁니다.

```
[ChaLocal] 'malchiki-mazhory' 세이브를 씁니다
```

실기 확인: 기본 세이브를 구운 APK 를 깨끗이 깔고(골드 50,000 · 차 1대),
런처로 전체 해금 세이브를 넣은 뒤 켜니 그대로 살아 있었습니다
(골드 999,999,999 · 차 30대 · 드라이버 12명, 예외 0건).

## 처음 깔 때

구형 SDK 앱이라 안드로이드가 창을 둘 띄웁니다. 둘 다 통과해야 뜹니다.

1. **권한 검토** → `계속`
2. **구버전 안내** → `확인`

## 게임 안에서도 세이브를 돌려씁니다

APK 안에 **겹판(overlay)** 을 하나 넣었습니다. 화면 왼쪽 아래 `SAVE` 를
누르면 칸 여섯 개가 뜹니다 — 지금 판을 칸에 넣고(SAVE), 칸을 불러오고
(LOAD), 지웁니다(DEL). 칸 파일은 세이브 옆에 `slot01.json` 처럼 놓입니다.

`LOAD` 는 게임을 닫습니다. 다시 켜면 그 칸으로 시작합니다 — 게임이
상태를 메모리에 들고 있어 파일만 갈아 끼워서는 화면이 안 바뀝니다.

맨 윗줄은 **지금 판**이고, 그 뒤에 어느 칸에 담겨 있는지 붙습니다.

```
NOW  G 23.346  T 9.984  CAR 4  DRV 8   -> SLOT 3
NOW  G 23.346  T 9.984  CAR 4  DRV 8   (not saved)
```

칸 파일과 글자를 통째로 견주므로, 저장한 뒤 게임을 더 하면 `(not saved)`
로 돌아갑니다. "지금 이대로 담겨 있는가"를 그대로 나타냅니다.

맨 아랫줄은 이 APK 가 어느 판인지 알려 줍니다. **구울 때 박은 값**이라
앱 안에서는 바꿀 수 없습니다(`LOCALAPK.md`).

```
MODE  LOCAL    (runs on its own, no server)
MODE  SERVER   127.0.0.1:8888   needs chacnserver.py + adb reverse
```

서버판에서는 칸이 로컬판 몫이라는 줄도 함께 뜹니다 — 서버판은 상태를
PC 가 들고 있습니다.

NGUI 프리팹은 하나도 안 건드립니다. Unity 의 구식 `OnGUI` 로만 그려서
자산 쪽 위험이 없습니다. 대신 이 빌드의 사정 때문에 모양이 정해졌습니다.

- **한글이 안 나옵니다.** 글꼴이 `Arial` 하나뿐인데 한글 글리프가 없고
  시스템 글꼴로 대체되지도 않습니다(실기에서 한글 줄만 통째로 비었습니다).
  그래서 이름 대신 **숫자**로 보여 줍니다 — `G 999,999,999 T 10 CAR 30 DRV 12`.
  어느 판인지는 오히려 이쪽이 빨리 보입니다.
- **글자 크기를 못 키웁니다.** `UnityEngine.dll` 이 깎여 있어
  `GUIStyle.fontSize` 도 `.font` 도 없습니다. `GUI.matrix` 로 화면 전체를
  2.6배 키웠습니다.
- **단색 판을 못 만듭니다.** `Texture2D` 에 `SetPixel` 도 생성자도 없습니다.
  반투명 상자를 일곱 겹 포개 불투명하게 만들었습니다.
- **`GUI.Button` 이 손가락에 반응하지 않습니다.** 그려지기는 하는데 눌리지
  않습니다. 그래서 그리기와 누르기를 갈라, 자리 비교는 `Input.GetTouch` 로
  직접 합니다.

실기 확인: 기본 세이브(골드 50,000 · 차 1대)로 돌던 중에 칸 1(전체 해금)을
`LOAD` → 앱이 닫히고 → 다시 켜니 골드 999,999,999 · 차 30대 · 드라이버 12명.
예외 0건.
